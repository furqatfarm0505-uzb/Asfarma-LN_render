# Фармацевтик Ўқув Бот — Render.com

## Нима ўзгарди?

1. **Интерфейс**: барча inline (хабар остидаги) тугмалар ўрнига энди **пастки
   (typing қатори ёнидаги) доимий клавиатура** ишлатилади — 2-расмда
   кўрсатилган кўринишда. Маълумотлар асосий ойнада оддий хабар сифатида
   чиқади, тугмалар эса ҳар доим пастда туради ва ҳар бир экран учун
   алмаштирилади (Бош меню → препарат → бўлимлар → ва ҳ.к.). Барча иконкалар
   (emoji) сақлаб қолинди.
   - Истисно: админга янги фойдаланувчи сўрови келганда чиқадиган
     «✅ Рухсат бериш / ❌ Рад этиш» тугмалари inline ҳолида қолди — чунки бу
     навигация эмас, балки бир марталик, аниқ хабарга боғлиқ амал (бир вақтда
     бир нечта сўров келиши мумкин).
2. **Хостинг**: Railway ўрнига **Render.com** учун созланди (қуйида).

## Render.com'да жойлаштириш

### 1-қадам: GitHub репозитория
Янги **private** репозитория яратиб, шу файлларни юкланг:
- `main.py`, `ready_texts.py`, `questions.py`
- `requirements.txt`, `Dockerfile`, `render.yaml`, `.gitignore`

> ⚠️ `__pycache__`, `.xlsx`, `converter.py` файлларини юкламанг

### 2-қадам: Render'да сервис яратиш
**Энг осон йўл — Blueprint (render.yaml) орқали:**
1. [render.com](https://render.com) га GitHub билан киринг
2. **New → Blueprint** ни босинг ва репозиториянгизни танланг
3. Render `render.yaml` файлини ўзи топади ва сервисни созлайди

**Ёки қўлда:**
1. **New → Web Service**
2. Репозиторияни танланг, **Runtime: Docker** ни танланг (Dockerfile
   автоматик топилади)
3. Plan: **Free** (ёки барқарорроқ ишлаши учун **Starter**, қуйида изоҳ бор)

### 3-қадам: Environment Variables
Render dashboard → **Environment** бўлимига қўшинг:

| Variable | Value |
|----------|-------|
| `BOT_TOKEN` | BotFather дан олинган токен |
| `ADMIN_ID` | Сизнинг Telegram ID рақамингиз |

`PORT` ни қўшишингиз шарт эмас — Render буни ўзи автоматик беради, бот эса
шу портда кичик health-check веб-сервер очади (Render Web Service талаби).

### 4-қадам: Deploy
Логда қуйидагилар чиқса — тайёр 🎉:
```
Бот фаолият бошлади (polling режими)...
🌐 Health-check сервери 10000-портда ишга тушди.
```

## ⚠️ Муҳим: Render Free план ва «уйқуга кетиш»

Render'нинг **бепул Web Service** плани 15 дақиқа давомида HTTP сўрови
келмаса, сервисни «уйқуга» юборади — бот шу пайтда Telegram'дан хабар
олмай қолади. Иккита йўл бор:

1. **Бепул, лекин доимий уйғоқ туриш учун**: [UptimeRobot](https://uptimerobot.com)
   ёки [cron-job.org](https://cron-job.org) каби хизматда ҳар 5–10 дақиқада
   `https://<сиз-берган-ном>.onrender.com/health` манзилига сўров юборадиган
   монитор созланг.
2. **Тўлиқ ишончли ишлаши учун**: Render'да **Starter** планга ўтинг
   (тахминан $7/ой) — бу ҳолда сервис ҳеч қачон уйқуга кетмайди.
